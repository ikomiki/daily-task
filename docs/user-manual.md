## 1. アプリ概要

**Habits** は、毎日の習慣タスクを管理するための Web アプリです。

### 主な機能

- **習慣タスクの登録** — 毎日・曜日指定・N日ごとなど柔軟な頻度でタスクを登録できます
- **毎日の記録** — 今日のタスクを「完了 / スキップ / 失敗」で記録します
- **集計・統計の確認** — タスクごとの完了率、連続達成日数などをスタッシュ画面で確認できます
- **履歴の閲覧** — 過去の記録を日付降順で遡って確認できます
- **時刻通知** — 各時間帯の設定時刻に、未完了タスクがある場合はブラウザ通知を受け取れます
- **オフライン対応** — インターネット接続がない状態でも操作でき、接続が戻ると自動で同期されます

## 2. はじめ方

### 2.1 アカウントの作成

1. アプリのURL にアクセスします
2. 「新規登録」を選択します
3. **メールアドレス** と **パスワード（6文字以上）** を入力して登録します
4. 登録が完了すると、自動的に「今日のタスク」画面に移動します

### 2.2 登録直後の初期データ

アカウント作成時、以下の時間帯とサンプルタスクが自動で設定されます。不要なものは後から削除・変更できます。

| 時間帯 | 通知時刻 | タスク名 | 頻度 |
|-------|---------|--------|------|
| 朝 | 07:00 | 歯を磨く | 毎日 |
| 朝 | 07:00 | メールを確認する | 平日（月〜金） |
| 朝 | 07:00 | 今日のタスクを見直す | 平日（月〜金） |
| 朝 | 07:00 | 不燃物のゴミ捨て | 第2・第4木曜 |
| 夜 | 21:00 | 運動する | 3日に1回 |
| 夜 | 21:00 | 掃除する | 2週ごと（土曜） |

### 2.3 ログイン

登録済みのアカウントでアプリを使用する場合:

1. 「ログイン」画面でメールアドレスとパスワードを入力します
2. ログイン後は「今日のタスク」画面が表示されます
3. セッションは自動で保存されるため、次回以降はログイン不要です（デバイスやブラウザの設定によります）

## 3. 初期設定

### 3.1 時間帯の設定

タスクは「時間帯」でグループ分けされます。タスクを追加する前に、自分のライフスタイルに合った時間帯を設定してください。

**設定画面へのアクセス:** 今日のタスク画面のヘッダーから「設定」→「時間帯の設定」

#### 時間帯を追加する

1. 「時間帯の設定」画面で「時間帯を追加」ボタンをクリックします
2. **時間帯名**（例: 朝、昼、夜）を入力します
3. **通知時刻**（例: 07:00）を設定します
4. 「作成」ボタンをクリックします

#### 時間帯を編集する

1. 変更したい時間帯の「編集」ボタンをクリックします
2. 名前や通知時刻を変更して「保存」をクリックします

#### 時間帯を削除する

- 「削除」ボタンをクリックします
- **注意:** そのタスクに属するタスクが1件でもあると削除できません。先にタスクを削除またはアーカイブしてください
- また、最後の1件は削除できません（最低1件の時間帯が必要です）

### 3.2 通知の設定

アプリをフォアグラウンド（表示中）で開いているときに、時間帯の通知時刻に合わせてブラウザ通知を受け取れます。

**設定画面へのアクセス:** 「設定」→「通知設定」

1. 通知設定画面で現在の通知状態を確認します
2. 「通知を許可する」ボタンが表示されている場合はクリックします
3. ブラウザの確認ダイアログで「許可」を選択します

**注意:** 通知はアプリを開いている間のみ機能します（v1 仕様）。バックグラウンドでの通知は現在対応していません。

## 4. タスクの登録

### 4.1 タスクを追加する

1. ヘッダーの「タスク管理」をクリックします
2. 「新規追加」ボタンをクリックします
3. 以下を入力して「作成」をクリックします
   - **タスク名** — 必須（例: 日記を書く）
   - **時間帯** — セレクトボックスから選択
   - **頻度** — 詳細は下記参照

### 4.2 頻度の設定

タスクがどのくらいの頻度で発生するかを設定します。

#### 毎日

毎日タスクとして表示されます。追加設定は不要です。

#### N日ごと

```
例: 3日ごと、開始日: 2026-05-17
→ 5/17, 5/20, 5/23 ... に表示
```

- **間隔（日数）** を入力します（1以上の整数）
- **開始日** を設定します（既定値: 本日）

#### 曜日指定

```
例: 月・水・金
→ 毎週月曜・水曜・金曜に表示
```

- 曜日のチェックボックスを選択します（複数選択可）

#### 曜日 + 第N週

```
例: 第1・第3月曜
→ 毎月の第1月曜と第3月曜に表示
```

- **曜日** のチェックボックスを選択します
- **第N週** を選択します（未指定の場合は毎週）

#### N週ごと

```
例: 2週ごと水曜、開始日: 2026-05-21
→ 5/21, 6/4, 6/18 ... に表示
```

- **間隔（週数）** を入力します
- **曜日** をドロップダウンから選択します（単一選択）
- **開始日** を設定します

### 4.3 タスクを編集する

1. 「タスク管理」画面で対象タスクの「編集」ボタンをクリックします
2. 名前・時間帯・頻度を変更して「保存」をクリックします

### 4.4 タスクをアーカイブする

タスクを削除せず非表示にしたい場合はアーカイブを使います。

1. タスク編集画面の下部にある「このタスクをアーカイブ」ボタンをクリックします
2. タスクは今日のタスク画面に表示されなくなります
3. 「タスク管理」画面でアーカイブ済みタスクを展開して確認できます

### 4.5 タスクを復元する

1. 「タスク管理」画面で「アーカイブ済み（N件）」セクションを展開します
2. 対象タスクの「復元」ボタンをクリックします

## 5. 毎日の操作（今日のタスク画面）

### 5.1 画面の見方

今日のタスク画面では、本日の頻度条件に合致するタスクが時間帯ごとにグループ化されて表示されます。

- **時間帯名** と **通知時刻** がグループのヘッダーに表示されます
- 各タスクには「完了」「スキップ」「失敗」の3つのボタンがあります

### 5.2 ステータスを記録する

| ボタン | 意味 | 表示色 |
|-------|------|------|
| 完了 | タスクを達成した | 緑 |
| スキップ | 意図的にスキップした（連続記録は途切れない） | 黄 |
| 失敗 | タスクを達成できなかった（連続記録がリセットされる） | 赤 |

**操作方法:**

- ボタンをクリックすると、その状態が即座に記録されます
- **同じボタンをもう一度クリックすると、記録が取り消されます**（白抜き表示に戻ります）
- 別のボタンをクリックすると、状態が切り替わります

### 5.3 スキップと失敗の違い

- **スキップ** — 「今日はやらないことにした」という意図的な選択。連続達成記録（ストリーク）は維持されます
- **失敗** — 「やろうとしたができなかった」または「うっかり忘れた」。連続達成記録がリセットされます

## 6. 統計を見る（スタッシュ画面）

### 6.1 画面へのアクセス

ヘッダーの「スタッシュ」をクリックします。

### 6.2 表示される統計

各タスクについて以下の統計が表示されます。

| 項目 | 説明 |
|------|------|
| **完了** | 今まで「完了」として記録した回数 |
| **スキップ** | 今まで「スキップ」として記録した回数 |
| **失敗** | 今まで「失敗」として記録した回数 |
| **連続** | 現在の連続完了日数（スキップは無視、失敗でリセット） |
| **対象日数** | タスク作成日から今日までで、そのタスクが予定されていた日数（スキップ日数を除く） |
| **完了率** | 完了数 ÷ 対象日数（%表示。対象日数が0の場合は「—」） |
| **最終完了** | 最後に「完了」として記録した日付（未記録は「—」） |

### 6.3 オフライン・未同期バッジ

画面上部に以下のバッジが表示される場合があります。

- **オフライン** — インターネットに接続されていない状態です
- **同期前 N件** — 操作がまだサーバーに送信されていない件数です

接続が回復すると自動的に同期が行われ、バッジが消えます。

## 7. 履歴を確認する（履歴画面）

### 7.1 画面へのアクセス

ヘッダーの「履歴」をクリックします。

### 7.2 操作方法

1. ドロップダウンから確認したいタスクを選択します（アーカイブ済みタスクも選択できます）
2. そのタスクの記録が日付の新しい順に表示されます
3. 直近31日分は即座に表示されます
4. それ以前の記録は「もっと読み込む」ボタンをクリックして取得します

### 7.3 表示されるステータス

| 表示 | 説明 |
|------|------|
| 完了 | その日「完了」として記録された |
| スキップ | その日「スキップ」として記録された |
| 失敗 | その日「失敗」として記録された |

記録がない日（未操作の日）は履歴に表示されません。

## 8. 設定を変更する

### 8.1 時間帯の管理

「設定」→「時間帯の設定」で時間帯の追加・編集・削除ができます（[3.1 参照](#31-時間帯の設定)）。

### 8.2 通知の管理

「設定」→「通知設定」でブラウザ通知の許可状態を確認・変更できます（[3.2 参照](#32-通知の設定)）。

### 8.3 ログアウト

ヘッダーの「ログアウト」をクリックするとログアウトできます。ログアウトするとすべてのデータはサーバー側に保持され、次回ログイン時に再度同期されます。

## 9. オフライン利用について

### 9.1 オフラインでできること

インターネット接続がない状態でも以下の操作が行えます。

- 今日のタスク画面の閲覧
- タスクのステータス記録（完了 / スキップ / 失敗）
- スタッシュ画面の閲覧（キャッシュされたデータ）

### 9.2 オフライン中の変更の取り扱い

オフライン中の操作はデバイスに一時保存されます。インターネット接続が回復すると自動的にサーバーに同期されます。

### 9.3 未同期件数の確認

スタッシュ画面で「同期前 N件」というバッジが表示されている場合、その件数の操作がまだサーバーに送信されていません。接続状態を確認してください。

## 10. PWA としてインストールする

Habits アプリは PWA（Progressive Web App）対応のため、アプリのようにデバイスのホーム画面に追加できます。

### iOS（Safari）

1. Safari で Habits アプリを開きます
2. 下部の「共有」ボタン（□に↑のアイコン）をタップします
3. 「ホーム画面に追加」をタップします
4. 名前を確認して「追加」をタップします

### Android（Chrome）

1. Chrome で Habits アプリを開きます
2. 右上のメニュー（⋮）をタップします
3. 「ホーム画面に追加」または「アプリをインストール」をタップします
4. 確認ダイアログで「追加」をタップします

### PC（Chrome / Edge）

1. アドレスバーの右端にあるインストールアイコン（PC に矢印が入ったアイコン）をクリックします
2. 「インストール」をクリックします

インストール後は、ブラウザを使わずにアプリのように起動できます。

## 11. よくある質問

### 「同期前 N件」とは何ですか？

タスクのステータス記録など、サーバーにまだ送信されていない操作がN件あることを示します。インターネット接続が回復すると自動的に送信されます。

### 通知が届かない場合は？

以下を確認してください。

1. **通知設定画面**（設定 → 通知設定）で許可状態が「許可済み」になっているか確認します
2. **ブラウザの設定**でこのサイトへの通知が許可されているか確認します
3. **アプリを開いている**ことを確認します（v1 ではフォアグラウンド通知のみ対応）
4. **時間帯の通知時刻**が正しく設定されているか確認します（設定 → 時間帯の設定）

### アーカイブしたタスクはどこへ行きますか？

「タスク管理」画面の「アーカイブ済み（N件）」というセクションに格納されます。クリックして展開すると確認できます。復元ボタンで元に戻すことも可能です。

### タスクを完全に削除したい

現在のバージョンではタスクの完全削除機能はありません。不要なタスクはアーカイブすることで今日のタスク画面から非表示にできます。

### 過去の記録を修正したい

現在のバージョンでは過去の記録の修正機能はありません。

### 複数のデバイスで使いたい

同じアカウントで複数のデバイスからログインすると、データはリアルタイムで同期されます。

### パスワードを忘れた場合

現在のバージョンではパスワードリセット機能は未実装です。管理者にお問い合わせください。

### アプリが更新されたら何が変わりますか？

PWA は自動更新に対応しています。新バージョンが公開されると、次回アプリを開いたときに自動的に最新版に更新されます。
